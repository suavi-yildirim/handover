    Send my episodes

    The file holds, for each episode:

    • the robot's joint positions, speeds and motor commands, 30 times per second (simulated, no camera images or sound)
    • your steering inputs, the task, its result and score, and the devices you used
    • the game version and a random contributor ID kept in this browser, which links your episodes together

    Failed attempts are included; training filters them out. Nothing else about you is in the file.

    The file is released under CC BY 4.0. Anyone may use, change and share it, including for commercial work, if they credit the Handover contributors.

    Sending is public. The file goes into a public GitHub issue on the project's repository. GitHub keeps issues and their history, so the file can't be fully removed later. Your IP address is visible to GitHub, as with any web request. You need a GitHub account to post the issue.
